# LifeOS — apk_planner

اپلیکیشن اندروید Personal OS طبق Master Prompt (فارسی/RTL-first، Kotlin + Jetpack Compose).

برای تاریخچه‌ی کامل باگ‌ها و فیچرهای پیاده‌شده در هر فاز، `BUGS_AND_GAPS.md` را ببینید. این فایل نتیجه‌ی یک ممیزی مستقل UI است که پس از گزارش کاربر مبنی بر «پرش/کرش در برخی صفحات» و «آیتم‌هایی که داخل کادر نیستند» انجام شد.

### بررسی شد، مشکلی پیدا نشد

برای شفافیت — این بخش‌ها هم به‌طور کامل بازبینی شدند اما مشکلی نداشتند:
- `HabitsScreen` (شامل بخش «بهترین رکورد»، که از قبل به‌درستی پیاده‌سازی شده بود — `habit.longestStreak` در `HabitCard` نمایش داده می‌شود)
- `RoutinesScreen` (`CreateRoutineDialog` از قبل `verticalScroll` صحیح داشت)
- `GoalsAndProjectsScreen` (`GoalCard`/`ProjectCard`، ردیف‌های نوار پیشرفت — همه با `weight`/`fillMaxWidth` درست پیاده‌سازی شده بودند)
- `AIChatScreen` (لیست پیام‌ها در `LazyColumn` است، ذاتاً اسکرول‌پذیر)

## فیچرهای جدید (درخواست کاربر)

- **اعلان قبل از موعد کار** — در `EditTaskDialog`، بخش «یادآوری‌ها» حالا یک ردیف چیپ سریع («۵ دقیقه قبل»، «۱۵ دقیقه قبل»، «۳۰ دقیقه قبل»، «۱ ساعت قبل»، «۱ روز قبل») دارد که به‌جای انتخاب دستی ساعت مطلق، یک یادآوری با فاصله‌ی مشخص قبل از زمان برنامه‌ریزی‌شده‌ی کار (`task.alarmTimeMillis`) می‌سازد. فقط وقتی کار زمان مشخصی داشته باشد نمایش داده می‌شود (چون «قبل از موعد» بدون موعد معنی ندارد).
- **بهترین رکورد در عادت‌ها** — در بررسی مشخص شد این فیچر از قبل در `HabitsScreen`/`HabitCard` پیاده‌سازی شده بود (`habit.longestStreak`، محاسبه‌شده در `HabitsViewModel.toggleHabitStreak`)؛ کار اضافه‌ای لازم نداشت.
